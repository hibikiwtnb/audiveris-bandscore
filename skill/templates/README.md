## 模板是什麼

一個模板就是**剛好包住那個符號的正方形**，由人在譜面上挑 3 個左右清楚的例子，照座標剪下來，對齊後取平均。
人負責「這是不是那個符號、剪多大」，程式負責對齊和比對。模板看起來必須一眼就認得出是那個符號。

- **灰階**：學和比對都用原圖灰度（3×3 中值），不二值化。灰度門檻只用來判斷位置（哪裡是譜線）。
- **沒有遮罩**：方塊裡每個像素都參與比對。方塊只包住符號，符桿、旁邊的音符大多在方塊外；方塊裡在例子之間不一致的地方（例如穿過邊緣的符桿）平均後變淡，影響自然變小。
- **譜線先擦掉**：學和比對前，都把長橫線（譜線、加線）上下都白的部分擦成白色，兩邊規則相同。
- **比對**：正規化相關係數，不受印刷深淺影響。門檻是 Audiveris 的 `crossMinGrade`（0.8）。

| `cross_line.png` | 被譜線或加線從中間穿過的叉頭（樣子不同）；有就和 `cross.png` 一起用 |
| `cross_ledger.png` | 踩在粗短加線上的叉頭（加線比 X 寬，樣子不同）；有就一起用。叉頭的模板每個位置都試，取吻合度最高的 |
| `slash.png` | 吉他譜的斜線（實心；意思是前一個和弦照這個節奏再彈）；有就在所有非鼓的五線譜上找 |
| `open.png` | 鼓譜上 Hi-Hat 符桿／符頭上方的開音記號（小圓圈 `o`） |
| `closed.png` | 鼓譜上 Hi-Hat 符桿／符頭上方的閉音記號（十字 `+`） |
| `chord_<根音>b.png` | 和弦名的根音連同 ♭（`chord_Db.png` 是 D♭），以根音字母高為單位（不是行距）。OCR 會把這種字型的小 ♭ 讀丟（`D`）或讀成數學符號（`E$`），有模板時用來補 ♭：模板對齊在 OCR 讀到的根音字母上，只用 ♭ 那一塊判斷（字母本身對不帶 ♭ 的字母也一樣吻合）。只在 hints 寫了降號開頭調號（`org.audiveris.omr.text.ChordFlats.openingFifths=-4` 之類）的曲子使用；分數過門檻（Audiveris `minFlatGrade` 0.55）就補 ♭，沒過照 OCR 原樣 |
| `key_sharp.png`、`key_flat.png` | 調號的 ♯、♭（單一個，長方形：寬 1.15、高 2.9 行距，旁邊的記號不進方塊）。兩個都有時，Audiveris 在每行有音高的五線譜開頭重讀調號：♯ 的 7 個位置、♭ 的 7 個位置（照 `key_layout.txt`）全部比對一次，每個位置記下模板吻合度和墨水，再一次判斷是哪一種調號（沒有、1–7 個 ♯、1–7 個 ♭）最符合「前 n 個有、之後沒有」。和原本讀的不同就換掉（log：`key N read with the templates, not M`，附每個位置的「吻合度/墨水」）。鼓譜表、TAB、一線譜不讀 |
| `key_layout.txt` | 調號記號在本書的位置，單位是該行自己的線距：譜號右緣到第 1 個記號中心（高音、低音譜號分開）、記號間距、記號中心離它的線／間的上下偏移（♭ 偏上約半個線距）。用 `tools/learn_key_layout.py <曲>:<調號> ...` 從已經讀對的調號量（印出中位數和範圍，抄進檔案）；同一本書各曲一致，不同書不同（例：♯ 離高音譜號 μ's 1.43、Sunshine 1.74） |
| `drum-set.xml` | 本書的鼓譜位置對應（格式同 Audiveris `app/res/drum-set.xml`），只寫和共用表不同的位置；有就蓋過共用表。例：`lovelive_muse_4513870037718` 的 hi-hat 在最上線 |
| `check_<名稱>.png` | 學這個模板用的例子（剪下、對齊後）和最右邊的模板，放大；給人看，程式不讀 |

## 學一個模板

1. 在 `input/omr_in/` 的頁面上（Audiveris 讀的那張圖）找 3 個以上清楚的例子，放大量出中心座標（頁面像素）；例子可以來自好幾頁。
2. 量每一頁例子所在譜表的行距（鼓譜表可能比其他譜表小），以及剛好包住符號的方塊邊長（以行距為單位）。
3. 執行（每頁一個 `--from`）：
   ```bash
   python3 tools/learn_template.py templates/<書名> --name <cross|cross_line|cross_ledger|slash> --box <邊長> --from <omr_in 頁.png> <行距> X,Y X,Y ... [--from ...]
   ```
   調號模板（`key_sharp`、`key_flat`）用 `--box 1.15 --height 2.9`（長方形）；例子取自 `.omr` 裡已經讀對的調號的 `key-alter` 外框中心。
   和弦模板（`chord_<根音>b`）的「行距」改給**根音字母的高度**（頁面像素），`--box 1.4`，中心是根音左緣到 ♭ 右緣、♭ 頂到字母底的中點。
   書裡沒出現過的降號根音（例如 G♭）用 `tools/compose_chord_template.py` 拼：本書的普通字母（G）加上其他根音的 ♭，照例子裡的距離放。
   第一個例子決定模板的中心，要量準；其他例子在 ±2 像素內對齊到第一個。
   同一個符號在不同地方長得差很多時（踩在譜線上、踩在粗加線上），分成不同名稱的模板，不要平均在一起。
4. 把 `check_<名稱>.png` 給使用者看，形狀對了才 commit。
